# 《禁闭求生 (Grounded)》体验增强工具箱 · GroundedQoL

一款专为 Steam 版 **《禁闭求生 (Grounded)》** 打造的轻量级体验增强 Mod，内置**全中文游戏内悬浮菜单**与 **“M” 键大地图实时雷达**。

如果你在游玩《禁闭求生》时遇到过这些烦恼：
- 背包和箱子格子总是不够用，同类材料堆叠上限太低；
- **简易难度太简单、中等难度打怪又太刮痧**，但切自定义模式又会锁 Steam 成就；
- 找**普通乳牙、高级乳牙**和稀有资源全靠对着网页攻略一张张对照，找洞穴里的乳牙更是找得头大；
- 反复刷基础材料、造工作台和建家太耗时间；
- 探险或打 Boss 不小心死了，背包掉在毒气洞、水底或地图另一头，跑尸捡包又累又怕卡地形；
- 和朋友**多人联机当房主**，希望全队一起玩得更爽快。

那么 **GroundedQoL** 就是为你准备的——**所有开关与倍率均可在游戏内随时实时调节，不会把存档切为自定义模式，不影响 Steam 成就解锁**。

## 核心功能介绍

### 1. “M” 大地图乳牙全显 & 全图资源/生物实时雷达
- **乳牙与高级乳牙开箱即用**：按 `M` 打开游戏原生大地图，地图上会自动标出所有**未采集的普通乳牙（亮蓝圆点）**与**高级乳牙（金色菱形）**；也可按需开启 SCA.B 配色显示，或灰显已采集的乳牙。
- **全游戏资源、矿点与昆虫自由追踪**：在菜单中支持**简体中文 / 英文检索**与分类筛选（采集点/矿石、散落物品、生物/昆虫、全图可扫描资源、宝箱/原始科学点等），支持多选追踪，自动分配高对比度配色并在地图右侧展示图例与数量统计。
- **动态追踪、击杀/采集即消点、重生自动复现**：
  - 徘徊移动中的昆虫（如狼蛛、黑寡妇、瓢虫等）会在大地图上实时跟随更新位置；
  - 采集乳牙、挖掉矿点、摘走资源或击杀昆虫后，对应标记会自动从地图上消失；
  - 只要不是一次性收集品，资源点或昆虫在游戏内刷新重生后，标记会自动重新打回地图上。
- **悬停距离 & 上下高度差提示**：在 M 地图上将鼠标移到任意标点上，会弹出提示卡片，显示中文名称、与你的直线距离，以及 **`↑ 上方` / `↓ 地下/下方` / `≈ 同高度`** 高度差——找地下洞穴、树根或高处的乳牙特别省心。
- **一键放原版全队路标 & 联动原版扫描仪**：
  - 悬停在任意标点上按 **`G` 键** 或 **`Ctrl + 左键`**，可直接在该坐标放置游戏原版 3D 路标，导航清晰且联机队友也能看到；
  - 菜单中支持**一键解锁全图原版资源扫描仪**，点击列表右侧的 **`[原版热区(全队)]`** 还能把对应物品的原版红色热区同步给全队。
- **顺滑贴合原版地图**：拖拽移动与缩放地图时，标点会以游戏原生帧率同步贴合，自动适配 1080P / 2K / 4K 与窗口/全屏模式。

### 2. 物品堆叠上限倍率（背包 & 箱子通用）
- 支持自由调节 **`1x ~ 50x`**（内置 `1x / 5x / 10x / 20x / 50x` 快捷档位，默认 **`10x`**），大幅减少背包与储物箱被同类物品占满的困扰。
- **装备防误合保护**：自动跳过武器、防具、工具等原版堆叠上限为 `1` 的单件装备，避免耐久度或强化属性出现异常。

### 3. 战斗伤害倍率自由微调
- 支持独立调节**玩家伤害倍率（`0.5x ~ 10.0x`，默认 `1.5x`）**与**怪物伤害倍率（`0.2x ~ 3.0x`，默认 `1.0x`）**。
- 可在原版中等/哇哦难度下微调出最舒服的战斗节奏，**不会触发自定义模式，不影响 Steam 成就**。

### 4. 采集入包与肩扛搬运数量倍率
- 支持自由调节 **`1x ~ 20x`**（默认 **`3x`**），采用**「地上 1 倍爆出、入包前同步乘倍率」**架构（见 [ADR-0005](./docs/adr/0005-pickup-multiplier-and-transient-hauling-hook.md)）：
  - 锤橡果、砍植物、挖黏土/虫、击杀昆虫时，地上爆出保持原版 1 倍清爽不卡顿，按 `E` 拾取进背包、空手自动装备、手持同类叠加或搜刮虫尸直入背包时，**首次采集即与左下角 HUD 播报同步生效**；
  - 支持**野生昆虫掉落物**与**易腐昆虫生肉**（如幼虫肉、蚜虫肉、象鼻虫肉等，自动按空槽补发副本）；
  - 可选同步作用于**草板 / 杂草茎等肩扛搬运物**（仅砍倒瞬间瞬时缩放并立刻还原原版值，单株总计封顶 12 根且绝不削减原版掉落，零模板污染）以及**地面天然散落物直拾**（树枝、植物纤维、鹅卵石、小蘑菇等）；
  - 内置四重防刷拦截：玩家丢弃/投掷物、射出回收的箭矢、拆毁建筑/取消蓝图返还物、储物箱/烤肉架/晾干架交互拿取、制作产出与不可堆叠武器/防具/工具一律严格保持 1 倍。

### 5. 无材料秒建 & 工作台免费制作
- **建造无需材料立刻建成**：开启后，放置工作台、墙体、箱子等任意建筑蓝图会直接建成，无需收集材料；另提供**“一键建成已放置的未完工蓝图”**按钮，可瞬间补完之前摆好的建筑虚影。
- **工作台 / 背包免费制作工具与道具**：开启后，在工作台和背包中合成工具、武器、装备或消耗品均无需消耗任何材料，立刻制作完成。
- **可选解锁全部配方**：支持随时一键全开或一键关闭无材料模式，玩腻了随时切回原版生存体验。

### 6. 死亡背包保留、耐久保护与一键找回背包
- **死亡背包保留（默认关闭，按需开启）**：开启后，玩家死亡时**背包内全部物品均完整保留在身上，不生成掉落背包**；直接原地覆写运行时游戏模式设置，**绝不切换存档为自定义模式，不影响 Steam 成就**，关闭开关即无损还原原版难度规则。
- **独立可选：免除死亡装备耐久惩罚（默认关闭）**：可按需单独开启，免除死亡时已穿戴装备扣除耐久的原版惩罚。
- **一键找回掉落背包（瞬移到脚边）**：
  - **一键找回我的背包**：自动唤醒远距离尚未流式加载的掉落背包，严格排除建筑/储物箱拆毁产生的战利品袋与已空背包，将属于你的全部非空掉落背包在**你正前方地面以小扇形错开摆放**（防碰撞弹飞），按 `E` 即可当场拾取；
  - **找回全队背包（各回本人脚边）**：多人联机时由房主一键把每位在线队友的掉落背包瞬移到各自正前方地面（离线玩家的背包自动送至房主脚边方便代收）。

## 适用版本与安装方法

- **当前最新版本**：`v1.1.0`（适配 Steam 版 Grounded `v1.4.7`，兼容 DirectX 12 与 DirectX 11，支持 Windows 10 / 11 64 位）。
- **安装步骤（3 步完成，无需额外运行库）**：
  1. 前往本仓库的 [Releases 页面](https://github.com/XinLinYu/grounded-toolkit-mod/releases/latest) 下载最新版绿色安装包 `GroundedQoL_v1.1.0.zip`。
  2. 在 Steam 库中右键点击 **Grounded** → **管理** → **浏览本地文件**，依次进入目录：
     ```text
     Grounded\Maine\Binaries\Win64\
     ```
     确认该文件夹内有 `Maine-Win64-Shipping.exe`。
  3. 将压缩包内的 **`dwmapi.dll`** 和 **`ue4ss`** 文件夹全部解压复制到上述 `Win64` 目录下即可。
- **启动方式**：直接从 Steam 正常启动游戏即可，无需第三方启动器。

## 常见问题（FAQ）

**Q1：会影响 Steam 成就解锁或导致封号吗？**  
不会。本插件完全不把存档切换为“自定义模式”，Steam 成就正常解锁；《Grounded》为合作生存游戏且无在线反作弊系统，正常与好友联机使用即可。

**Q2：刚进入存档按 `M` 为什么地图上还没出现乳牙？**  
读取存档后插件会延迟约 `2.5` 秒等待世界实体加载完毕再做首次全图扫描。稍等 2~3 秒重新按 `M` 即可看到全部乳牙；也可以按 `Insert / F8` 打开菜单点击**“立即刷新世界资源”**。

**Q3：按 `Insert` 或 `F8` 没有弹出菜单怎么办？**  
请确认 `dwmapi.dll` 和 `ue4ss` 文件夹确实放在了 `...\Grounded\Maine\Binaries\Win64\`（与 `Maine-Win64-Shipping.exe` 同级），而不是放进了游戏根目录或子文件夹里。

**Q4：在菜单搜索框里打中文看不到候选框怎么办？**  
插件默认在窗口/无边框全屏模式下自动唤醒并定位系统原生输入法候选窗，在独占全屏下自动切换为内置自绘候选条；若因第三方输入法皮肤或 Steam 覆盖层遮挡了系统候选窗，可在菜单「**快捷键与联机说明**」页将「输入法候选框模式」切换为 **「强制使用内置自绘候选条」**。

**Q5：怎么彻底卸载？会影响我原来的存档吗？**  
不会改动或损坏存档格式。想恢复纯净原版，只需关闭游戏后删除 `Maine\Binaries\Win64\` 目录下的 **`dwmapi.dll`** 和 **`ue4ss`** 文件夹即可 100% 干净还原。

  - 草板/杂草茎等肩扛搬运物采用 `SpawnLoot` / `OnDeath` / `OnDamaged` 三入口瞬时 Pre/Post 缩放还原（单株总计封顶 12 根且绝不削减原版掉落）；玩家丢弃/投掷/箭矢、拆建返还、箱子/烤肉架/晾干架拿取、合成产出与单件武器/防具/工具严格保持 1 倍。
- **堆叠上限、战斗伤害、无材料秒建/免费制作与死亡保护（100% 保留 Steam 成就，[ADR-0001](./docs/adr/0001-in-place-gamemode-settings-achievement-safety.md) / [ADR-0002](./docs/adr/0002-backpack-recovery-lod-wakeup.md)）**：
  - 物品堆叠上限 `1x ~ 50x`（自动保护单件装备）、玩家/怪物伤害独立倍率、无材料秒建 + 一键建成未完工蓝图、工作台/背包免费制作（无损还原）、可选解锁全部配方；
  - 死亡背包保留、独立免除死亡耐久惩罚，以及一键找回我的背包/全队背包（四重只读零唤醒过滤，绝不误唤醒未加载实验室宝箱，多背包扇形错开落地并联机同步）。
- **IPC 队列可靠性与全量自动化回归测试**：
  - 跨重启会话隔离（`session` + `actions` 批量队列 + 原子重命名认领），彻底杜绝并发竞态丢单或跨重启误裁剪；
  - 配备 29 项 Lua 全场景回归用例（`L1 ~ L28` 含 `L5a`）与真实 DX12 / DX11 SwapChain 自动化回归测试套件。

### 从源码编译、测试与部署
1. 克隆仓库（含子模块）：
   ```bash
   git clone --recursive https://github.com/XinLinYu/grounded-toolkit-mod.git
   ```
2. 准备环境：Visual Studio 2022 / 2026（含 C++ 桌面开发工具与 CMake）、Windows 10/11 SDK，并确保游戏目录已安装适配 Grounded `v1.4.7` 的 RE-UE4SS。
3. 运行部署脚本（可传入本机 Grounded 安装路径）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\deploy.ps1 -GameDir "G:\SteamLibrary\steamapps\common\Grounded"
   ```
   编译产物会部署到游戏目录，同时在 `dist/` 下生成可直接分发给联机队友的绿色压缩包。
4. 运行自动化回归测试（可选）：
   ```powershell
   # Lua 业务逻辑全场景回归测试（需 Lua 5.3+）
   lua.exe .\lua\tests\lua_regression_test.lua
   # C++ 真实 DX12 / DX11 SwapChain 悬浮层回归测试
   .\overlay\build\Release\overlay_regression_test.exe dx12 .\overlay\build\Release\GroundedQoLOverlay.dll
   .\overlay\build\Release\overlay_regression_test.exe dx11 .\overlay\build\Release\GroundedQoLOverlay.dll
   ```
